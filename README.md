# Mini CRM

A simple and responsive Customer Relationship Management (CRM) web application for managing contacts, leads, and clients.

## About the Project

Mini CRM is a frontend CRM application built using HTML, CSS, and JavaScript.

The application allows users to manage contacts, view useful dashboard statistics, track leads and clients, and organize customer information through a simple and responsive interface.

Data is stored in the browser using `localStorage`, so contacts remain available after refreshing the page.

## Features

* Dashboard with CRM statistics
* Total contacts count
* Leads vs. clients overview
* Contacts added this week
* Recent activity
* Contacts management
* Add new contacts
* Edit existing contacts
* Delete contacts
* Contact validation
* Contact categories/status
* Local storage data persistence
* Responsive design
* Dark mode
* Light/dark theme switching
* Sidebar navigation
* Clean and modern UI
* Mobile-friendly layout

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/AshwiniChoubey/mini-crm.git
```

### 2. Open the project

```bash
cd mini-crm
```

### 3. Run the application

Open `index.html` in your browser.

You can also use the Live Server extension in VS Code for easier development.

## Project Structure

```text
mini-crm/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

### index.html

Contains the structure of the CRM application and its different pages/components.

### style.css

Contains the application's styling, responsive layouts, colors, spacing, buttons, cards, forms, and dark mode styles.

### script.js

Contains the application logic, contact management, navigation, validation, localStorage functionality, dashboard statistics, and theme switching.
